## 教材內容

### 循序結構（Sequential Structure）

循序結構是所有程式中最基礎的架構。指令是由上而下、一條接著一條按照順序單向執行，中間沒有任何跳躍、分支或折返。例如：早晨起床鬧鐘響起 → 刷牙洗臉 → 換制服 → 吃早餐。每一步都按照既定順序發生。

### 選擇結構（Selection Structure）

當流程遇到需要判斷條件時，會根據條件成立與否，決定走向哪一條路徑，這就是選擇結構（又稱條件判斷分支）。常見形式有：
1. 單向選擇：若條件成立就執行某動作，不成立就什麼都不做直接跳過（例如：若下雨就帶傘）。
2. 雙向選擇：條件成立走路徑 A，不成立走路徑 B（例如：考試成績 >= 60 及格，否則不及格）。

### 重複結構（Repetition Structure / 迴圈）

如果希望某些指令重複執行多次，重複結構能大幅簡化程式碼，避免複製貼上上百行指令。常見類型有：
1. 指定次數重複（計數迴圈，如 FOR 迴圈）：預先知道要執行幾次，例如「原地開合跳重複 20 次」。
2. 條件成立時重複（條件迴圈，如 WHILE 迴圈）：依據條件動態決定是否繼續，例如「當水溫未達到 100°C 前，持續加熱」。特別注意：重複結構必須具有讓條件改變並終止迴圈的機制，否則會陷入停不下來的無窮迴圈！

## 教材提示詞

### 三大結構特徵對照表

```text
[循序結構]
指令 A -> 指令 B -> 指令 C (由上而下無分支)

[選擇結構]
條件成立？ -> 是 -> 執行區塊 A
          -> 否 -> 執行區塊 B

[重複結構]
重複條件滿足？ -> 是 -> 執行指令區塊 -> 折返檢查條件
              -> 否 -> 跳出迴圈結束
```
