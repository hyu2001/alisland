## 教材內容

### 流程圖四大標準符號字典（CNS 標準）

為了讓所有人都能正確無誤地理解流程圖，中華民國國家標準（CNS）與國際標準組織（ISO）制定了統一且具備特定意義的標準符號：
1. 端點符號（橢圓形 / 圓角矩形）：代表流程的「開始」或「結束」。通常流程圖只會有一個「開始」端點，可有一個或多個「結束」端點。
2. 輸入／輸出符號（平行四邊形）：代表資料由外部讀入（例如輸入帳號密碼、讀取感應卡餘額），或運算結果向外顯示（例如螢幕顯示歡迎詞、印出總分）。
3. 處理程序符號（長方形）：代表系統內部的運算處理、變數計算或一般動作（例如計算「總和 = A + B」、更新資料庫、扣款 20 元）。
4. 決策判斷符號（菱形）：代表條件判斷，必定會有一個輸入端點，並分出至少兩條流向分支（條件成立與不成立，或 Yes 與 No）。

### 流程線規範與動態追蹤：決策流程圖怎麼跑？

繪製流程圖必須遵循嚴格的黃金規則：
1. 流程線一律必須帶有箭頭：明確指示資料與控制的唯一流向，不可使用無箭頭的普通直線。
2. 菱形決策線必須標註分支結果：由菱形分出的每一條流向線，一定要清楚標註『成立／不成立』、『Yes／No』或『是／否』！
動態追蹤案例（週末活動決策）：
起點：橢圓『開始』 →
決策：菱形『是否下雨？』
分支 A (成立 / Yes)：走左路 → 長方形『去圖書館看書』
分支 B (不成立 / No)：走右路 → 長方形『去戶外打籃球』
匯合：兩條路徑最終匯流至橢圓『結束』。

### CNS 流程圖繪製黃金檢查清單

```text
[ ] 端點是否皆為橢圓形？（不可誤用長方形）
[ ] 資料輸入（如輸入帳密）是否使用平行四邊形？
[ ] 運算處理（如加減計算）是否使用長方形？
[ ] 條件判斷是否使用菱形？
[ ] 菱形分出的兩條分支線是否有標註「成立 / 不成立」或「Yes / No」？
[ ] 所有流程連接線是否皆清楚標示前進方向箭頭？
```
